# Hooked since the C64 — a paper film about Lars Krahl

A 53-second, hand-made-looking **paper-collage animation** about
[lars-krahl.de](https://www.lars-krahl.de/). Everything is drawn, animated, scored
and mixed in plain JavaScript (Canvas 2D + Web Audio). There are no image files:
every cut-out, torn edge, scrap of tape and paper fibre is generated in code.

- **Watch:** open `dist/index.html` in any modern browser (it's a single file and
  works offline), or play `dist/lars-krahl.mp4` (1080p30, H.264/AAC).
- **Two soundtracks:** the default is a **C64/SID-style chiptune score**. The original
  orchestral "storybook" score is still available: open `dist/index.html?score=storybook`
  or watch `dist/lars-krahl-storybook.mp4`.
- **Controls:** click/space = play/pause · ←/→ = seek 5 s · F = fullscreen.

## How it's made

| Part | Technique |
|------|-----------|
| Visuals | `src/core.js` bakes each cut-out sprite: torn/deckled edges, a white "scissor" margin, paper grain, a drop shadow, and **3 line-boil variants** (hand-drawn ink via [rough.js](https://roughjs.com)) cycled at 8 fps. Idle motion is stepped at 12 fps for a stop-motion feel. Every frame is a pure function of time, so renders are deterministic. |
| Camera | All scenes sit on one big kraft-paper table. The camera pans between them with a slight zoom dip, hand-held drift and impact shakes, and dives into the C64 screen, which is itself a scene. The offline render adds real multi-sample motion blur on fast moves. |
| Voice | **Kokoro-82M** (open-weight neural TTS, voice `af_heart`), generated by `tools/voiceover.py`. Each line was checked with Whisper speech recognition, both on its own and inside the final mix. |
| Music | Two original scores in `src/audio.js`, both locked to the same 104 BPM grid as the visuals. **Chiptune (default):** a synthesized SID-style score in A minor with PWM pulse leads (saw minus delayed saw, with the delay modulated), resonant filtered bass, 50 Hz chord arpeggios, noise drums and a dotted-eighth echo. The most cartoonish sound effects are swapped for 8-bit ones. **Storybook:** sampled piano, xylophone, nylon guitar, harp, bassoon, flute and clarinet (via the `tonejs-instrument-*` packages). |
| Sound effects | About 40 procedurally synthesized cartoon and foley sounds (paper rustle, pencil scribble, whooshes, stamp, boing, Karplus-Strong string twang, pipe clanks, water, zaps…) cued from the scenes. |
| Mix | Voice chain (HPF, presence EQ, compression), music ducking under narration, convolution reverb built from a generated impulse response, bus compression. Loudness is about −14 LUFS with a −1.8 dBFS peak ceiling. |
| Fonts | Caveat, Gochi Hand, Permanent Marker, Press Start 2P, Patrick Hand, Fredericka the Great (all OFL, via `@fontsource`). |

## Rebuild

```bash
npm install                                   # playwright (renderer only)
python3 tools/voiceover.py <kokoro_dir> <out> # optional: regenerate narration
tools/prepare_assets.sh <node_modules> <out>  # copy/trim samples, voice, fonts
npm run build                                 # -> dist/index.html (self-contained)
npm run render                                # -> dist/lars-krahl.mp4 (needs ffmpeg + Chromium)
node tools/render.mjs --preview 3.5,12,44     # -> .frames/preview/*.png
```

Source layout: `src/core.js` (engine) · `timeline.js` (tempo, scene times, narration and sound-effect cues) ·
`characters.js` · `scenes1-3.js` · `render.js` (camera, table, film grain) · `audio.js` · `main.js` (player).
